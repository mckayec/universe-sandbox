## Revision for implementation-review.md (IR1–IR3)

ChatGPT's review of head d08c4d2 returned three blocking findings. The branch was rebased onto main 2a4c95e (main had only gained docs commits and the Vite 7.3.7 lockfile update), and the fixes are in commit **b733585**. This file is updated in the commit after it, which is the PR head reported in `status.md`.

Gate rule used for every IR2 and IR3 edit: a later fact is gated to a book only when one of these gives that book:
1. `corrections.md`, `lore-audit.md` or `implementation-review.md`.
2. The pack's own Chronicle event for the same fact. The review uses this precedent itself for New Sparta and l3/l3b.
3. The book the sentence itself names ("In Rise…", "In Endymion…", "in Golden Son…"). Where a sentence names several books, it is gated to the latest one.

Anything without such a source was **cut**, not gated. No new facts were added. Text that moved to a gate keeps its original wording, apart from a few splits so that each fact can sit at its own book.
