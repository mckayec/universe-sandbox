## AU01-ORDER-01 — finite implementation request

**Severity: Medium. Evidence: C, repository observation plus opened chart reproduction R2.** At PR48 lines385 and389, the generator uses `(i + 5)` for both `worlds[id].status` and `worlds[id].facts[0][1]`. Thus Jes–Ishi are numbered fifth–fourteenth. R2 shows Ashyn, Roshar and Braize inside the belt, followed by the ten named giants. The belt is not another planet. PR24 and PR37 already produce the correct fourth–thirteenth sequence. Their matching values corroborate a branch divergence; they are not independent canon sources.

Target **PR48 only**. Change the two expressions in this generator to `(i + 4)`. Preserve the one-to-ten gas-giant index `(i + 1)`.
