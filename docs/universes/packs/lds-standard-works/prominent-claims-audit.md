# Ten prominent claim checks — evidence boundaries

2026-10-26. These ten claims were selected for their prominence in the atlas framing and core journeys, not to maximize a corroboration score. Primary support is in the opened source registers cited below. The table separates confirming an attributed text from independently confirming an event. It is a bounded ten-claim audit, not the still-unfinished re-verification of every prominent/low-confidence statement in the expanded corpus.

This is an honest limitation, not permission to manufacture another source.
