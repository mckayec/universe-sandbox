The [declaration index](content-audit/supplementary-declaration-index.csv) identifies **1,271 table declaration/source-view rows**, with exact source lines and hashes. Nineteen are direct re-declarations of the already-accounted primary IDs. The remaining **1,252 views are not 1,252 unique additional objects**: aliases, documentary dossiers, overlapping families and repeated source views remain distinct from entity counts. Neither number is an additional primary-reading count.

This is category-level implementation accounting, not a claim that every supplementary sentence received a new copy-by-copy build comparison. Categories marked partial contain already-represented shared settings, episodes or concepts, but their supplementary source views are not fully imported. No category is certified fully implemented. Declaration rows identify source evidence for the category disposition; they are not individual new content verdicts. In particular, name/key absence alone is not treated as proof that an entity is absent.

The explicit [section whitelist](content-audit/supplementary-sections.json) and [generator/checker](content-audit/supplementary-accounting.py) preserve prose-only sections as well as table rows. DP13–36, the BoM disambiguation paragraph and JS—History person index therefore do not disappear because they lack a table. Hashes establish reproducibility of this repository snapshot, not evidence that a primary source was read. Run:
