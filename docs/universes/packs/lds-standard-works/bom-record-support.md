# Book of Mormon record-by-record source-support audit

2026-10-26. **195/195 stable inventory IDs checked against preserved official Church chapter bodies:** BP30, BE23, BJ11, BC20, BXP74, BXJ17, BXE8, BXC6, BXR6. The ledger is [bom-record-support.csv](bom-record-support.csv), one defining row per stable ID, with source URLs, original source-range/copy context and outcome. Crosswalks, repeated table views and239 BMC chapter cards are not added to the denominator. Families are checked at their stated summary scope, not counted as hundreds of atomized people or events. BXP02 remains a reuse; a checked reference is not necessarily a new entity.

## Method and completed check

Read the actual proposed copy/route/relationship rows, then re-extracted and reread supporting official verse bodies from the preserved239-chapter cache. This pass included the old migration/city/event spine; all new material-place definitions; actor-specific added journeys; complete named lists in3Nephi19, Mormon6 and Ether1; supporting dynasty/kinship passages; and ordinance/doctrine/chronology passages behind the broad families. The earlier full-body reading provides surrounding context; a checksum and inherited C flag alone were not treated as semantic verification. The source cache contains current official text, with captured footnotes kept distinguishable from numbered body.

**Result:**185 supported-text records and10 corrected-supported records. No unsupported modern coordinate, new calendar conversion, or independently verified ancient event is approved by this result. Retained limitations include narrative geography, unnamed protagonists, source-specific chronology, repeated names, interrupted or intended travel, visions/prophecies, and the acknowledged son/descendant wording differences. Scripture support verifies the attribution, not the described miracle's historicity.
