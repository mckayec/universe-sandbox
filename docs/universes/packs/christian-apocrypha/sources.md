# Source register index

2026-10-26. Source keys are file-scoped. The following registers distinguish primary text witnesses from scholarly catalogues and institutional reception statements; a link is not by itself a reading claim.

- [Corpus and method](corpus-and-method.md): AP-C01–06 reception sources, actual inspected sections and access notes.
- Deuterocanonical source register: `deuterocanonical-sources.md`; ledger names the edition used for each chapter/section.
- [Expanded OT sources](expanded-ot-sources.md): XO namespace; edition/translation and partial-access limitations retained.
- NT-apocrypha source register: `nt-apocrypha-sources.md`; fragments and alternative text forms distinguished.
- Related pseudepigrapha: `related-pseudepigrapha.md` source section.
- [Pilate research](pilate-research.md): PG/PL primary witnesses, PS scholarly catalogue and separately identified James1924introduction.
- [Reused gazetteer evidence](geography-reuse.md): exact previous research revisions and underlying geographic sources; not new independent source checks.

Only short original summaries and metadata are published. No wholesale source captures or modern translations are uploaded. Retrieval/reading notes identify actual scope; file hashes, if supplied by validation, identify artifacts rather than evidence that a source was read.

- [Marian witness and scholarship](marian-research.md), [Pseudo-Matthew witness and scholarship](pseudo-matthew-research.md): selected form, rights and later expansions identified.
- [2 Esdras supplement](2esdras-supplement.md): WEB chapters 5–16, exact per-chapter URLs and observed KJV/WEB differences; overlap with the expanded-OT ledger, not duplicate corpus coverage.
